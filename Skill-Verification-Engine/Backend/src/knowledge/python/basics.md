Python is a high-level, interpreted, general-purpose programming language known for its readability.

Python uses indentation (whitespace) to define code blocks instead of braces or keywords.

Python supports multiple paradigms: procedural, object-oriented, and functional programming.

Variables in Python are dynamically typed; no type declaration is needed.

Common data types include int, float, str, bool, list, tuple, dict, and set.

Lists are ordered, mutable sequences defined with square brackets: my_list = [1, 2, 3].

Tuples are ordered, immutable sequences defined with parentheses: my_tuple = (1, 2, 3).

Dictionaries store key-value pairs: my_dict = {"name": "Alice", "age": 30}.

Sets are unordered collections of unique elements: my_set = {1, 2, 3}.

Strings are immutable sequences of characters; support slicing, f-strings, and methods like .split(), .join(), .strip().

Python uses 0-based indexing. Negative indexing accesses elements from the end: my_list[-1].
