HTML (HyperText Markup Language) defines the structure and content of web pages.

HTML5 introduced semantic elements: header, nav, main, section, article, aside, footer.

Semantic HTML improves accessibility, SEO, and code readability.

Common elements: div, span, p, h1-h6, a, img, ul/ol/li, table, form, input, button, textarea, select.

Forms use input types: text, email, password, number, date, checkbox, radio, file, submit.

The alt attribute on img provides alternative text for screen readers and when images fail to load.

ARIA attributes enhance accessibility: role, aria-label, aria-hidden, aria-live.

The <meta> viewport tag enables responsive design: <meta name="viewport" content="width=device-width, initial-scale=1">.

CSS (Cascading Style Sheets) styles HTML elements with properties for layout, color, typography.

The CSS cascade determines which styles apply based on specificity, source order, and importance.

Specificity hierarchy: inline styles > IDs > classes/attributes > elements. !important overrides all.

The box model: content + padding + border + margin. box-sizing: border-box includes padding/border in width.

Flexbox is a one-dimensional layout: display: flex. Properties: justify-content, align-items, flex-direction, flex-wrap, gap.

CSS Grid is two-dimensional: display: grid. Properties: grid-template-columns, grid-template-rows, grid-area, gap.

Responsive design uses media queries: @media (max-width: 768px) { } to adapt layouts to screen sizes.

CSS units: px, em, rem, %, vw, vh, fr (grid), ch. rem is relative to root font size.

CSS animations: @keyframes name { from { } to { } } applied with animation property.

CSS transitions: transition: property duration timing-function delay; for smooth state changes.

Pseudo-classes: :hover, :focus, :nth-child(), :first-child, :last-child, :not().

Pseudo-elements: ::before, ::after, ::placeholder, ::selection.

CSS variables (custom properties): --primary: #6366f1; used as color: var(--primary);

Position: static, relative, absolute, fixed, sticky. z-index controls stacking order.

BEM naming convention: .block__element--modifier for maintainable CSS.
